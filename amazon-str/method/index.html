Weekly STR cleanup that actually cuts zero-order spend

Leaving auto campaigns alone for months is how ACoS quietly rot. This is a 30-minute Search Term Report pass you can run without another SaaS seat.

  1. Export Sponsored Products Search Term Report (7–30 days). Sort by Spend descending.
  2. Kill (exact negative) if clicks are in the ~10–20 range (tighter if low margin) with 0 orders, or spend already looks like ~2–3× what a break-even order costs you — or the query is clearly wrong intent.
  3. Harvest terms with 3+ profitable orders into exact; negate them in the auto/source so they stop cannibalising.
  4. Watch mid-spend / low-orders another week — don’t nuke on one weird week if the 4-week trend is fine.

Tune the click/spend floors to your margin. Not Amazon financial advice. Not affiliated with Amazon.
